# Telegram-бот: настройка за 15 минут (бесплатно)

1. Бот. В Telegram откройте @BotFather, отправьте /newbot, придумайте имя и логин (заканчивается на bot). Скопируйте токен (длинная строка с двоеточием). Никому его не показывайте.
2. Cloudflare. Зарегистрируйтесь на cloudflare.com (бесплатно). Меню Workers & Pages, Create, Create Worker, имя tiimdi-bot, Deploy. Нажмите Edit code, удалите весь текст, вставьте содержимое файла worker.js, нажмите Deploy.
3. Хранилище. Меню Storage & Databases, KV, Create a namespace, имя tiimdi-kv. Вернитесь в Worker, Settings, Bindings, Add, KV namespace: переменная KV, выберите tiimdi-kv.
4. Секреты. Settings, Variables and Secrets, Add, тип Secret: BOT_TOKEN (токен из шага 1) и WEBHOOK_SECRET (любая длинная строка из букв и цифр). Для канала еще CHANNEL_ID (например @mychannel).
5. Расписание. Settings, Trigger Events, Cron Triggers, Add: "20 */3 * * *" (проверка оповещений) и "0 4 * * *" (утренняя сводка, это 09:00 в Алматы).
6. Подключение. В браузере откройте адрес вашего воркера: https://tiimdi-bot.ВАШ-ПОДДОМЕН.workers.dev/setup?key=ВАШ_WEBHOOK_SECRET. Должно появиться {"ok":true,...}.
7. Проверка. Напишите боту /start, потом /rate и /alert USD 440.
8. Сайт. В файле data/site.js впишите bot: "ЛогинБота" (без @), загрузите на GitHub. На сайте появится блок "Сообщим, когда курс подойдет".
9. Канал (по желанию). Создайте канал, добавьте бота администратором, впишите CHANNEL_ID. Каждое утро в 09:00 бот опубликует курсы.

Данные пользователей (номер чата, язык, оповещения) хранятся только в вашем KV. Команда /stop удаляет их.
