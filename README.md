# Тиімді сәт: курс валют и цены на квартиры (Алматы)

Два раздела: **Валюта** (USD, EUR, RUB, CNY, GBP: курс Нацбанка, обменники и банки Алматы, подсказка, когда выгоднее) и **Квартиры** (ЖК BI Group и BAZIS-A на карте, цена за м2, рассрочка, ипотека, сравнение двух ЖК).

## Файлы

| Файл | Зачем |
|---|---|
| `index.html`, `app.js` | Сайт целиком |
| `currency/`, `apartments/` | Отдельные адреса для поисковиков |
| `data/fx.js`, `data/fx_nbk.csv` | Курсы валют (обновляет `collector/fx.py` каждый день) |
| `data/rates.js` | Средние курсы доллара по месяцам для сезонности |
| `data/apts.js` | ЖК: цены, условия, координаты (обновляются вручную) |
| `collector/fx.py`, `collector/common.py` | Сборщик курсов |
| `.github/workflows/daily.yml` | Ежедневный автозапуск на GitHub |
| `manifest.webmanifest`, `sw.js`, `icons/` | Установка на телефон как приложение |
| `sitemap.xml`, `robots.txt` | Для поисковиков |
| `_archive/` | Старые разделы (телефоны, машины). Сайту не нужны, можно не загружать |

## Обновить курсы вручную

GitHub, вкладка Actions, слева Daily-fx, справа Run workflow.
