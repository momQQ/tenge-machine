# Цены на iPhone в Казахстане

Сайт-каталог. Главная -> Смартфоны -> модель (18 Pro, 18 Pro Max, 18, Duo, архив iPhone 16) -> объем памяти -> график: цена в тенге по магазинам, курс доллара, цена в долларах. Цены собираются каждый день автоматически.

## Что где лежит

| Файл | Зачем |
|---|---|
| `index.html` | Сайт. Открывается двойным кликом или через Live Server |
| `data/prices.csv` | История цен. Одна строка на дату, модель и магазин |
| `data/rates.csv` | Курс доллара по месяцам (Нацбанк) |
| `data/data.js` | Создается скриптом автоматически, руками не править |
| `collector/products.json` | Какие модели и страницы магазинов отслеживать |
| `collector/collect.py` | Сборщик цен |
| `.github/workflows/daily.yml` | Ежедневный автозапуск на GitHub |

## Проверка сборщика на своем компьютере

В терминале VS Code, из папки проекта:

    python collector/collect.py

Нормальный результат:

    - iPhone 18 Pro 256 ГБ / iSpace
        OK: 849990 ₸ (заголовок страницы)
    ... всего 21 страница, в конце: Готово: успешно 21, с ошибкой 0

Если вместо цены ОШИБКА, сохраните страницу из браузера (Ctrl+S, "Веб-страница, только HTML") и проверьте разбор:

    python collector/collect.py --parse страница.html sulpak

## Как добавить модель или магазин

В `collector/products.json` модели лежат как "families" (семейство, например iPhone 18 Pro), внутри "variants" (объем памяти), внутри "stores" (магазин и ссылка). Чтобы добавить магазин, скопируйте блок `{"store": ..., "parser": ..., "url": ...}` в нужный вариант. Для нового магазина подойдет `"parser": "generic"`. Статус семейства: on_sale, soon, limited, archive.
Берите цену за наличные, одну конфигурацию памяти, один цвет.

## Курс доллара

Файл `data/rates.csv` пока обновляется вручную раз в месяц: добавьте строки `месяц,USD,средний курс` из таблицы Нацбанка.

## Важно

Перед запуском проверьте условия использования и robots.txt магазинов. Сборщик делает один запрос в день на страницу товара.
